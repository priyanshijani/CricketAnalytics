# 06_Tests/test_cases

Test case definitions, each mapped to a requirement in `07_Docs/00_Project_Plan.md`'s traceability
matrix: expected input, expected outcome, and how to verify it.

- `dq_test_cases.md` — data-quality gate and feedback loop (DQ-TC01 to DQ-TC11).
- `dw_test_cases.md` — warehouse load (DW-TC01 to DW-TC10).
- `rpt_security_test_cases.md` — reporting layer and least-privilege logins (RPT-TC01 to RPT-TC06, SEC-TC01 to SEC-TC06).
- `export_orchestration_test_cases.md` — CSV export and the orchestrator (EXP-TC01 to EXP-TC03, ORC-TC01 to ORC-TC06).
- `tableau_test_cases.md` — Tableau workbook and its extracts (TAB-TC01 to TAB-TC09).
- `sql_quality_test_cases.md` — reconciliation, business rules, referential integrity, performance (RC-xx, BR-xx, RI-xx, PERF-TC01-02).
